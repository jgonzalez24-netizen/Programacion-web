Actualmente estoy estudiando programación web, un área que me interesa porque permite crear páginas y sistemas que pueden ser utilizados desde internet. Durante mis estudios estoy aprendiendo diferentes tecnologías y conceptos que me ayudan a comprender cómo funciona una página web desde su estructura hasta su funcionamiento. Una de las cosas que estoy aprendiendo es HTML, que sirve para crear la estructura de una página. Con HTML puedo agregar títulos, textos, imágenes, enlaces, botones, listas y diferentes elementos que forman parte de un sitio web. También estoy aprendiendo CSS, que permite modificar la apariencia de las páginas, por ejemplo, cambiar colores, tamaños, posiciones, fondos, tipos de letra y la distribución de los elementos. Aunque al principio puede parecer complicado, poco a poco voy entendiendo cómo funciona.
